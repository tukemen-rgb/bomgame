# スマホ実機テストの手順

機械で分かることは `npm run mobile` で全部潰してある（5端末 × レイアウト検査、
タッチ操作だけで実際に潜る検査、個別ボタンの検査）。
**このドキュメントは「実機でしか分からないこと」だけを扱う。**

実機でしか分からないのは、だいたいこの4つ：

1. **指が届くか** — 画面の寸法は測れるが、親指の可動範囲は測れない
2. **重くないか** — 実機の GPU・熱・省電力設定でしか出ない
3. **音が出るか** — 実機のマナーモード・自動再生の制限でしか分からない
4. **遊べるか** — 落ちながら狙った隙間へ寄せる操作が、指で成立するか

---

## 1. スマホで開く

**一番簡単なのは Artifact の URL。** スマホのブラウザでそのまま開ける
（このセッションで公開したもの。他人には見えない）。

それ以外の方法：

| 方法 | やり方 | 向いている場面 |
|---|---|---|
| **単一ファイルを送る** | `dist/deep-fall.html` を AirDrop / メール / チャットで自分のスマホに送り、ブラウザで開く | ネットワークが無い場所、機内モードでも動く |
| **同じ Wi-Fi のPCから** | PC で `npm start`、スマホで `http://<PCのIP>:8901/` | 手元でソースを直しながら実機で見る |
| **GitHub Pages** | `.github/workflows/pages.yml` を手動実行（後述） | 何度も端末を変えて試す |

**依存も外部通信も無いので、`dist/deep-fall.html` 1ファイルで完全に動く。**
オフラインでも遊べる。

### GitHub Pages について

`pages.yml` を用意してあるが、**手動実行（workflow_dispatch）だけ**にしてある。
`git push` では絶対に動かない。

**これを実行すると、ゲームが公開 URL でだれでも見られる状態になる。**
リポジトリが private でも Pages は公開されるので、それでよいか確認してから実行すること。
実行前に GitHub の Settings → Pages で Source を「GitHub Actions」にしておく必要がある。

## 2. 端末チェック画面を使う

タイトルの **「📱 端末チェック」**（または URL に `?device=1`）で開く。

- **自動判定** — 画面サイズ・押す的の寸法・はみ出し・HUD の見え方・保存・fps。
  fps は「測る」を押すとその端末で2秒間実測する
- **実機で確かめること** — 9項目。触ってから ○ か × を押す
  （同じものをもう一度押すと取り消し）
- **「📋 結果をコピー」** — 全部まとめてテキストになる。**そのまま貼って送れば報告になる**

実機テストで一番困るのは「何が起きたかを持ち帰れないこと」なので、この画面がその役目。

---

## 3. 実機で確かめる9項目

端末チェック画面に並んでいるものと同じ。**それぞれ「なぜ聞いているか」はこう。**

| 項目 | なぜ聞くか |
|---|---|
| 左右のボタンに親指が自然に届く | ボタンは 56px 確保してあるが、位置が届くかは実機だけ |
| 落ちながら狙った隙間へ寄せられる | このゲームの操作の全部。ここが × なら他は無意味 |
| 結晶（💠）を狙って拾える | 蛇行した列を追う操作。設計上は届く間隔にしてあるが、指で成立するか |
| 爆弾ボタンを押し間違えない | 左右ボタンの間にあるので、誤爆すると弾を無駄に失う |
| 岩と隙間が見分けられる | 盤面が 294〜386px に縮むので、40px のマスが 20px 前後になる |
| 深度・爆弾の残数が読める | 狭い画面では HUD が2〜3行に折り返す。読めるかは実機で |
| 音が出る | マナーモード解除で確認。WebAudio は最初のタップまで鳴らない仕様 |
| 動きが引っかからない | fps の数字が出ていても、間欠的に詰まることがある |
| 数分遊んでも熱くならない | 毎フレーム全画面を描いているので、発熱と電池は実機で見るしかない |

## 4. 併せて見てほしいもの

- **横持ちにしてみる。** 低い横画面には縦坑が入らないので、
  「画面を縦にしてください」の案内が出てゲームが止まるはず。
  縦に戻したらポーズ画面から自分で再開する（持ち替えている最中に動き出すと、その一瞬で死ぬ）
- **`R` に相当する設定**（演出を抑える）はキーが無いので、
  スマホでは OS の「視差を減らす」を入れて開くと最初から抑えた状態になる。
  端末チェック画面の「演出の抑制」に ON と出る
- **ゲームオーバーの広告枠**。2回目のゲームオーバーで出る。
  スキップが押せるか、結果画面に必ず戻るかを見てほしい

---

## 5. 結果の送り方

端末チェック画面の「📋 結果をコピー」を押して貼るだけでよい。
× が付いた項目と、その時どう感じたかを一言添えてもらえると直せる。

コピーがうまくいかない端末では、下に出るテキスト欄を長押しで選んでコピーできる。
