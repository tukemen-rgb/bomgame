サイト側が公開している要件（2026年8月時点で確認）と、用意したものの突き合わせ。

| サイト側の要件 | こちらの状態 | |

| 1作品 **200MB まで**の zip | **55.8 KB** | ✅ 余裕 |
| zip 内 **5,000ファイル以内** | **2ファイル** | ✅ 余裕 |
| HTML5 は **zip の直下に index.html** | 直下に置いてある | ✅ |
| アカウント作成 | **要対応**（本人しかできない） | ⚠️ |

⚠️ 要件はサイト側の都合で変わる。投稿前に upload ページの記載を見直すこと。

## 2. アップロードするもの

```
dist/deep-fall.zip     ゲーム本体（これをアップロード）
dist/press/            スクリーンショット4枚
  01-title.png         タイトル
  02-play.png          落下中。爆弾で岩を掘っている瞬間
```

作り直す時は `npm run pack` と `node tools/shots.js`。

## 3. フォームに入れる文章（そのまま使える）

### タイトル

```
DEEP FALL — 落ち続けろ
```

### 短い説明（1行）

```
落下は止められない。地面に触れたら終わり。爆弾で足元を掘りながら、どこまでも下へ。
```

### 説明文

```
主人公はひたすら落下します。地面に触れた瞬間にゲームオーバー。
止まることは許されていないので、下へ抜ける道を落ちながら作り続けるしかありません。

■ 抜け方は9種類
穴・二又・もろい岩・横に動く穴・開閉する穴・二重の動く穴・壁のボタン・埋まった爆弾。
どれも詰まったら自前の爆弾で掘れますが、爆弾は腰のポーチに3個だけ。
どこで使うかを決めてから落としてください。

■ 200m ごとに「ご褒美の間」
岩が1マスも無い区間が来ます。爆弾の補給、シールド、爆風アップ、結晶（点数）。
中身は5種類を巡回し、1000m ごとは全部盛りの大空洞、
10000m ごとは「地核の間」でシールドの上限を超えます。
深さに終わりはありません。目標は常に次の節目です。

■ 遊びやすさ
・スマホのタッチ操作に対応（横移動・急降下・爆弾の3ボタン）
・OSの「視差を減らす」設定を尊重し、画面揺れ・フラッシュ・色ずれを抑えられます
・インストール不要。通信もしないので、開いた後はオフラインでも遊べます

操作：← → 横移動 ／ ↓ 急降下 ／ Space 爆弾 ／ P ポーズ ／ R 演出を抑える
```

## 4. 投稿の手順

1. https://play-game-yard.com/ でアカウントを作る
2. `/upload/` を開く
3. `dist/deep-fall.zip` をアップロード（HTML5・zip 直下 index.html）
4. 上の文章を貼る／ジャンルとタグを選ぶ
5. `dist/press/` の4枚をスクリーンショットとして登録
6. ウイルス検査を待つ → 承認されればその場で公開

## 5. 公開後に確認すること

**投稿サイトは iframe でゲームを埋め込むことが多い。**そこで初めて出る問題があるので、
公開されたページで次を見てほしい。

- **音が鳴るか** — WebAudio は最初のクリック／タップまで鳴らない。
  iframe だと、その最初の1回が親フレームに吸われることがある
- **キー入力が効くか** — iframe にフォーカスが当たっていないと矢印キーが効かない。
  一度ゲーム画面をクリックしてから確かめること
- **矢印キーでページごとスクロールしないか** — こちらでは `preventDefault` しているが、
  埋め込み方によっては親側が動くことがある
- **スマホでボタンが押せるか** — 埋め込み枠が小さいと、
  「縦にしてください」の案内が出る条件に入ることがある
- **記録が保存されるか** — 最高到達を localStorage に置いている。
  サードパーティ Cookie を制限した iframe では保存できないことがある
  （その場合も遊べるが、記録が残らない）

**どれも「うちの不具合」ではなく「埋め込まれ方の問題」なので、
出たら埋め込み条件と併せて教えてほしい。**そこに合わせて直せる。
