# GAMEYARD への投稿

投稿先： https://play-game-yard.com/upload/
手引き： https://play-game-yard.com/guides/first-upload/

⚠️ 要件はサイト側の都合で変わる。投稿前に手引きを見直すこと（下記は2026年8月時点）。

## 1. アップロードするもの

| ファイル | どこに使うか |

## 2. 要件との突き合わせ

### ZIP

| 要件 | こちら | |
|---|---|---|
| **zip の直下に index.html** | 直下にある | ✅ |
| 200MB 以下 | 55.8 KB | ✅ |
| 5,000ファイル以下 | 2ファイル | ✅ |
| 展開後 400MB 以下 | 176 KB | ✅ |
| 素材の参照はすべて相対パス | **参照が1つも無い**（1ファイルで完結） | ✅ |
| ファイル名は半角英数字 | `index.html` / `README.txt` | ✅ |

**手引きが挙げている一番多い失敗は「フォルダごと右クリックで圧縮して、
index.html が1段深くなる」。** こちらは `tools/pack.js` がファイルを直接
zip に書き込んでいるので、この形にはならない（テストでも毎回確かめている）。

### 画像

| 要件 | こちら | |
|---|---|---|
| カバー1枚＋遊んでいる場面6枚まで | カバー1＋4枚 | ✅ |
| PNG / JPG / WebP | PNG | ✅ |
| 1枚 3MB まで | 最大 0.82MB | ✅ |
| 最小 600×315 | カバー 1920×1008 ／ 他 1260×1342 | ✅ |
| 最大 4096×4096 | 同上 | ✅ |
| UI が読める大きさ | 2倍で撮っている | ✅ |

`node tools/shots.js` が、出した直後にこの条件を自分で確かめる。

## 3. フォームに入れる文章

### キャッチコピー（8〜80字）

```
落下は止められない。地面に触れたら終わり。爆弾で足元を掘りながら、どこまでも下へ。
```

（41字）

### 説明文（40〜4000字）

手引きが「遊び方・操作方法・1回あたりのプレイ時間・動作を確かめた環境」を
入れるよう求めているので、全部入れてある。

```
主人公はひたすら落下します。地面に触れた瞬間にゲームオーバー。
止まることは許されていないので、下へ抜ける道を落ちながら作り続けるしかありません。

■ 抜け方は9種類
穴・二又・もろい岩・岩とひびの混在・横に動く穴・開閉する穴・二重の動く穴・
壁のボタン・埋まった爆弾。どれも詰まったら自前の爆弾で掘れますが、
爆弾は腰のポーチに3個だけ。どこで使うかを決めてから落としてください。

■ 200m ごとに「ご褒美の間」
岩が1マスも無い区間が来ます。爆弾の補給、シールド、爆風アップ、結晶（点数）。
中身は5種類を巡回し、1000m ごとは全部盛りの大空洞、
10000m ごとは「地核の間」でシールドの上限を超えます。
深さに終わりはありません。目標は常に次の節目です。

■ 操作
← → 横移動 ／ ↓ 急降下 ／ Space 爆弾を落とす
P ポーズ ／ M 音楽 ／ N 効果音 ／ R 演出を抑える
スマートフォンでは画面下にタッチボタンが出ます（横移動・急降下・爆弾の3つ）。
横持ちだと縦坑が画面に入らないので、縦にしてお使いください。

■ 1回あたりのプレイ時間
1回 1〜3分。短く何度も繰り返す形です。最高到達深度は端末に保存されます。

■ 遊びやすさへの配慮
OSの「視差を減らす」設定を尊重し、画面揺れ・全画面フラッシュ・色ずれを抑えられます
（Rキーでも切り替え可能）。インストール不要で、開いた後は通信しません。

■ 動作を確かめた環境
PC の Chrome 系ブラウザ。
スマートフォンは iPhone SE / iPhone 13 / Pixel 7 相当の画面サイズで、
タッチ操作だけで進めるところまで確認しています。
```

⚠️ 「動作を確かめた環境」は、実機で確認したら**実機名に書き換えること**。
いまは端末プロファイルでの確認までしかしていない。

### ジャンル（1つ）・タグ（10個まで）

```
ジャンル： アクション
タグ：    落下 / 高難度 / エンドレス / ブラウザ / スマホ対応 / 一人用 / 日本語 / ドット
```

サイト側の選択肢に合わせて調整すること。

## 4. 投稿の手順

1. https://play-game-yard.com/ でアカウントを作る
2. `/upload/` を開く
3. **形式は HTML5**、`dist/deep-fall.zip` をそのままアップロード（展開しない）
4. キャッチコピー・説明文・ジャンル・タグを上から貼る
5. カバーに `00-cover.png`、遊んでいる場面に `01〜04` を登録
6. **ウイルス検査が走る。終わるまでページを開いたままにする**
   （数十MBで数分。こちらは 55.8 KB なのですぐ終わるはず）
7. 通過したら公開 → URL が決まる

**更新したい時は、同じアカウントで同じ作品として投稿し直す。**
説明文もビルドも差し替わる（手引きに明記あり）。

## 5. 公開後に確認すること

**投稿サイトは iframe でゲームを埋め込むことが多い。**手引きには書かれていないが、
そこで初めて出る問題があるので、公開されたページで次を見てほしい。

- **音が鳴るか** — WebAudio は最初のクリック／タップまで鳴らない。
  iframe だと、その最初の1回が親フレームに吸われることがある
- **キー入力が効くか** — iframe にフォーカスが当たっていないと矢印キーが効かない。
  一度ゲーム画面をクリックしてから確かめること
- **矢印キーでページごとスクロールしないか** — こちらでは `preventDefault` しているが、
  埋め込み方によっては親側が動くことがある
- **スマホでボタンが押せるか** — 埋め込み枠が低いと、
  「縦にしてください」の案内が出る条件に入ることがある
- **記録が保存されるか** — 最高到達を localStorage に置いている。
  サードパーティ Cookie を制限した iframe では保存できないことがある
  （その場合も遊べるが、記録が残らない）

**どれも「うちの不具合」ではなく「埋め込まれ方の問題」なので、
出たら埋め込み条件と併せて教えてほしい。**そこに合わせて直せる。
