# 💣 BLAST RUSH

**爆風は、武器じゃない。絵筆だ。**

ボンバーマンの操作系を土台にしつつ、**勝敗を「倒した数」ではなく「塗った面積」で決める**
陣取りアクション。爆風が通った床は自分の色に染まり、自陣の上は速く走れて敵陣の上では遅くなる。
「塗る → 動きやすくなる → もっと塗れる」の好循環をどれだけ早く回せるかを競う。

**依存ライブラリ・ビルド・アセットは一切なし。** HTML と JavaScript だけで動く。

```
git clone <this repo>
cd bomgame
# そのまま index.html をブラウザで開くだけ
```

ローカルサーバーで見たい場合：

```
python3 -m http.server 8000
# http://localhost:8000
```

## 遊びかた

| | 移動 | 爆弾 | リモコン起爆 |
|---|---|---|---|
| **1P** | `←` `↑` `↓` `→` | `Space` | `Enter` |
| **2P** | `W` `A` `S` `D` | `F` | `G` |

`P` / `Esc` ポーズ、`M` BGM オン/オフ、`N` 効果音オン/オフ。
スマホ・タブレットでは画面下にタッチパッドが出る（1P のみ）。

### インク陣取りのルール

このゲームの核。ボンバーマンとの一番大きな違い。

- **爆風が通った床は自分の色になる。** ソフトブロックの上は塗れないので、
  塗り面積を伸ばすには結局ブロックを壊すことになる。
- **自陣の床は移動速度 +30%、敵陣の床は −26%。** 盤面の色がそのまま機動力の地図になる。
- **敵は歩いた跡を敵色に汚す。** 放置すると塗り率がじりじり削られるので、
  「無視して逃げ回る」が成立しない。
- **敵を倒すと、その場に半径2マスのインクが飛び散る。** 撃破は目的ではなく塗りの手段。
- **やられると足元の自陣が中立に戻る。** 死のコストを残機ではなく陣地でも払う。
- **連鎖させるほど一度に塗れる面積が跳ね上がる。** 連鎖が直接スコアと勝利条件に効く。

### モード

- **ひとりで塗る** — ノルマ塗り率（ステージ1で 57%、進むごとに上がって最大 70%）を
  達成すると、盤上に最初から見えている出口が開く。出口に入れば次のステージへ。
  パワーアップは持ち越し。ステージは無限に続き、進むほど敵が賢く・多くなる。
- **2人で塗り合い** — 時間切れの時点で塗り面積が広いほうがラウンド勝ち。先に3ラウンド先取で勝利。
  **やられても即敗北にはならない**（2秒スタン＋スタート地点へ戻され、足元の自陣が中立化）ので、
  撃ち合いだけでなく塗り合いのペース配分が勝負になる。

### アイテム

| | 効果 |
|---|---|
| 🔥 | 爆風が 1 マス伸びる（最大 9） |
| 💣 | 同時に置ける爆弾が 1 個増える（最大 8） |
| ⚡ | 移動速度アップ（最大 5 段階） |
| 🦵 | **キック** — 爆弾に体当たりすると滑っていく |
| ✴ | **貫通爆弾** — 爆風がソフトブロックを貫く |
| 📡 | **リモコン** — 導火線が止まり、起爆キーで好きなときに爆発させられる |
| 🛡 | シールド。被弾を 1 回肩代わりする（最大 3） |
| ♥ | 残機 +1 |
| ☀ | フルファイア。火力が一気に最大へ |

### コツ

- **床が赤く点滅しているマスは、これから爆風が来る場所。** ここさえ見ていれば死なない。
- **最初に自陣を一本の道として繋げる。** 点在させるより、走る線を作ったほうが機動力が上がる。
- 爆風に触れた爆弾は誘爆する。連鎖させるほど一度に塗れる面積が跳ね上がる。
- ノルマを超えてもすぐ出口に入らず塗り続けたほうが、塗りボーナス（塗り率 ×30点）で儲かる。
- 敵を短時間に続けて倒すと KILL COMBO でスコアが倍々になる。
- 制限時間が切れると敵が暴走（速度 1.55 倍）して増援も来る。粘らずに出口へ。
- リモコンを取ったら爆弾は自動で爆発しなくなる。起爆キーを忘れずに。

## 実装メモ

```
index.html          画面とHUD
css/style.css       UI
js/const.js         定数・共通ユーティリティ
js/audio.js         WebAudio による効果音とBGMの合成（音声ファイル 0 個）
js/fx.js            パーティクル / 画面揺れ / 衝撃波 / 浮かぶ数字
js/map.js           ステージ生成・BFS 経路探索・ステージ定義
js/entities.js      プレイヤー / 敵 / 爆弾 / アイテム
js/game.js          ゲームループ本体と全描画
js/main.js          入力・UI・メインループ
docs/RESEARCH.md    設計リサーチのまとめ
```

インク陣取りの実装は `js/map.js` の `ink` / `inkT` 配列（グリッドと同じ長さの `Uint8Array`）と、
`js/game.js` の `explode()` 内の 1 行 `this.map.paint(c.x, c.y, bomb.team)` が中心。
爆風セルの計算をそのまま塗りに再利用しているので、連鎖・貫通・キックといった
既存の爆弾ギミックが全部そのまま「塗りの戦術」になる。

爽快感まわりで意図的にやっていること：

- **爆風は中心から距離 × 16ms ずつ遅れて出る。** 十字に「伸びる」ように見える。
- **誘爆には 55ms のタメ。** 即時にすると連鎖が 1 発の爆発に潰れてしまう。
- **ヒットストップは完全停止ではなくスロー（`dt *= 0.18`）。** 止めると操作感が死ぬ。
- **色ズレ（chromatic aberration）は上限 5px、42px/s で減衰。** 派手さより盤面の可読性を優先。
- **移動はグリッド中心線への吸い付き付き。** 曲がり角でひっかからない。

詳しい設計判断の根拠は [docs/RESEARCH.md](docs/RESEARCH.md) に書いた。

## 動作確認

Chromium（Playwright）で自動スモークテストを回している：起動 → 1P プレイ →
連鎖爆発 → 出口 → ステージクリア → ステージ 9 の AI 放置シミュレーション → 対戦モード。
コンソールエラー 0 件、60fps を確認済み。
